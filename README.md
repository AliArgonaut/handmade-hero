
# Handmade Hero — Personal Learning Repository

This repository contains my work, experiments, and notes from following **Casey Muratori’s Handmade Hero**, a course where an entire game is built from scratch in **C/C++** with no engine and no hidden libraries.

Handmade Hero is known for its transparency, systems-level depth, and practical exploration of real-time game programming.  
This repo tracks my journey through that process — from platform layers to rendering, audio, memory systems, and architecture.

---

## Repository Contents

This repo includes:

- C/C++ source files following along with the series  
- Platform layer implementations (Win32/Linux depending on progression)  
- Renderer experiments  
- Build scripts  
- Notes summarizing each episode  
- Scratch files, prototypes, and learning exercises  
- Occasional small refactors or personal deviations from the video  

> **Note:** This is *not* the official Handmade Hero source.  
> It’s my personal learning archive inspired by the course.

---

## Goals of This Project

- Deepen my understanding of C/C++  
- Learn how real-time applications interact with OS APIs  
- Practice low-level memory management  
- Build a complete game from the ground up  
- Explore rendering, audio, input, threading, and performance topics  
- Reinforce learning through small experiments and annotations
